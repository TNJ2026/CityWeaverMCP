# 道路与交通规则（Paradox Wiki）

> 来源：cs2.paradoxwikis.com/Roads（1.0 版核实）+ /Traffic + 社区攻略共识。游戏已更新到 1.6.x，个别数字可能漂移；以游戏内实际 prefab 数据为准。

## 道路职能

- 两大职能：**通行 + 划区**。划区只能贴道路两侧（深向约 6 格 / 48m 有效）。
- 除高速外所有道路自带 **40MW 低压电容量**；非桥梁道路可**随路预铺水/污水管**（水管和电缆预建于道路下方）。空地也能独立拉管拉线，但沿路是标准做法。高速公路不承载低压电、给水或污水。
- 发电站、变电站、水塔、抽水站、污水处理厂和排污口的道路侧落在普通道路功能区格子上时，直接接入道路内置的对应线路，无需另铺接驳线。同一连续普通道路网络共享设施能力；独立道路片区要么建设对应设施，要么延长普通道路/兼容管网连接到已通水电污水的道路。抽水站必须同时临水、临普通道路；排污口必须临水，无法临路时用污水管接到道路。
- 路面越宽噪音越大，沿线地价越低——大路两侧不适合住宅。

## 道路分级（层级规则）

```
高速公路 ──立交──> 主干道(4-6车道) ──> 集散路(2-4车道) ──> 小区路(2车道) ──> 地块
```

| 等级 | 连接对象 | 路口间距建议 | 划区 |
|---|---|---|---|
| 高速 | 只接立交/匝道 | — | ❌ 禁止 |
| 主干道 | 接高速立交、接集散路 | 200-300m | 少量，避免高流量源直接贴 |
| 集散路 | 接主干道、接小区路 | 较密 | ✅ |
| 小区路 | 只接集散路 | 密 | ✅ 全部 |

- 高速基本是**单行道**，画路方向=车流方向（起点→终点），画反即废；服务车辆不能逆行单行道。
- 高速上禁止红绿灯；T 字路口比十字快约 40%（社区实测）；中流量路口用环岛。
- 环岛 4 种尺寸：小 ¥200 / 中 ¥500 / 大 ¥1000 / 特大 ¥1500，车道数自动适配连接路。
- 匝道做法：先用多一车道的高速类型画加速段，再接单车道高速形成合流匝道。

## 绘制工具

- 默认吸附：8m 划区格、90° 直角、建筑边缘、参考线、划区网格，可逐项关闭。
- 模式：直线 / 简单曲线 / 复杂曲线 / 连续 / 网格 / 平行（平行偏移 0.25-12 划区格）。
- 海拔：按 1.25 / 2.5 / 5 / 10m 步进抬升或下挖；负值先成路堑，更深成隧道；高架需下方净空。
- Replace 模式可就地升级道路类型、加装公交道/电车轨（高速、小巷、碎石路不能加电车轨）。

## 交通寻路（Traffic 页）

- 每辆车独立寻路，成本四要素：**时间**（成人首要）、**舒适**（老人首要，少转弯+近停车）、**钱**（青少年首要，油费+停车费）、**行为**（是否愿违规掉头；紧急车辆可违章掉头，其他车会避让）。
- 货运成本随距离增加 → 本地销售比外运更赚钱；把工厂放近外部连接可降低出口成本。
- 事故概率按路段计算：路况差、无路灯、恶劣天气增加概率；事故需警察清场+养护车清障，占用车道。
- 城际交通在两个外部连接之间自动择优路线——修了更短的穿城路线会把过境车流引进来。
- 养护：道路状况随使用衰减，需道路养护所（Road Maintenance Depot）派车修补，路况差减速+增事故。

## 检查清单（新城区连路时）

1. 高速→城市只经立交，不在高速上开口；
2. 每个片区经集散路上主干道，不让小区路直连主干道/高速；
3. 住宅不贴大路（噪音），用小区路接进地块；
4. 货运走廊（工业区→外部连接）独立，不穿住宅。
