# 本机构建与验收记录（2026-09-20）

以下是特定开发机器的历史记录，不是所有玩家或开发者的通用安装要求。项目首页的中英文 README 均以当前通用流程为准。

| 项目 | 当时检查结果 |
| --- | --- |
| 游戏路径 | `E:\SteamLibrary\steamapps\common\Cities Skylines II` |
| 游戏版本（`Player.log` 实测） | `1.6.2f1 (767.21d1) [6300.26419]` |

| 构建工具链契约 `CSII_UNITYVERSION` | `2022.3.62f2` |
| .NET SDK | `8.0.425` |
| 模组目标框架 / C# | `net48` / `9.0`，由官方 Mod.props 决定 |
| 工具链 Unity / Entities | `2022.3.62f2` / `1.3.10` |
| 官方后处理器运行时 | `.NET 6`（本机私有解压 `6.0.36`） |

**工具链版本与引擎版本不是同一个量。** `CSII_UNITYVERSION` 是官方工程读取的用户级注册表配置，决定 Mod.props 的引用程序集路径；它不随游戏更新自动改变，值为旧版不一定代表配置损坏。判断实际运行版本应看 `Player.log` 的 `Game version` 与 `Initialize engine version`，或 `Cities2.exe` 的文件版本；不一致时以 `Player.log` 为准。只有官方工具链报错时才核对该变量。

当时官方工程读取的用户级 `CSII_*` 环境变量已指向 E 盘游戏，无需修改共享 Mod.props。本机系统缺少 .NET 6，因此将微软 .NET Runtime 6.0.36 x64 解压到不纳入版本控制的 `.tools/dotnet`，并按发布元数据的 SHA-512 校验；下载来源和哈希保存在本机 `.tools/runtime-source.json`。`build.ps1` 仅在构建期间设置进程内 DOTNET_ROOT / DOTNET_ROOT_X64，完成后恢复。其他电脑仍需自行安装官方工具链、.NET SDK 和后处理器所需的 .NET 6 运行时。

2026-09-20 实测：普通权限环境中私有运行时可用，`-Stage` 与部署构建均成功，包含官方后处理和 Windows/macOS/Linux 三平台 Burst。官方后处理器直接读取用户级注册表中的 `CSII_UNITYVERSION`，只有进程环境变量和 MSBuild 参数并不够；构建脚本会提前诊断，详见[调用、事务与诊断](../workflows/operations.md)。

## 历史验收摘要

- 基础版本已通过游戏内加载、设置按钮和模拟回调验证；设置持久化当时尚未专项验证。
- 早期 MCP 版本通过暂存构建、官方后处理和 8 项通信/MCP 自动测试，并在主菜单和暂停城市中完成真实查询、建筑分页及实体详情联调；详见[验证记录](VALIDATION.md)。
- 0.2.0 在真实城市验证通用查询：发现 1229 种类型；878 种有实例的类型成功抽样，349 种无实例。部分嵌套原生数据明确标记不支持；`Deleted`/`Temp` 按设计排除。
- 1.23.1 于 2026-09-20 完成暂存和部署构建（官方后处理及三平台 Burst，0 错误），并通过当时的 134 项 MCP 自动测试。航道有奥本山存档的实机记录，见[航道指南](../guides/transport/WATERWAY-GUIDE.md)；路口预设与路边站台当时只有编译和接口测试覆盖，尚未实机验收。构建和接口测试不等于游戏内验收。

该记录只描述当时的环境与证据；运行中的游戏版本、工具链和测试数量以后可能变化。
