# 地图编辑器：地形、水体、资源、气候与环境

自 1.25.0 起，MCP 对已加载地图的 Editor 模式开放指定工具。`get_game_status.city_loaded` 仍只表示可游玩的城市；编辑器使用 `editor_ready`、`map_loaded` 判断，不能因为 `city_loaded=false` 就认定游戏没有地图。加载中、主菜单和其他模式仍拒绝地图操作。

## 当前范围与状态识别

`get_editor_state` 返回当前编辑器面板类型/标签、活动工具、地形数据是否就绪、暂停状态、资源类型和允许的工具清单。面板类型表示原生面板，不保证能解析所有弹窗文字；需要视觉确认时使用 `capture_game_view(include_ui=true)`。截图只捕获游戏，`get_camera_view` 提供地图镜头世界范围。

首版编辑已在游戏中打开的地图，不自动创建/加载另一张地图，不修改起始地块或元数据（1.26.0 新增对外连接资产放置），不发布地图。不能仅将所有城市工具取消模式限制；经济、人口、解锁及未验证的城市建设工具在编辑器中返回 `TOOL_NOT_AVAILABLE_IN_EDITOR`。

完整可玩地图还需在原生编辑器完成名称、起始地块和必要对外连接等检查。本版提供地形、水体、资源、植被、气候及环境参数编辑与原生保存窗口入口，不把编辑能力等同于完整地图已制作完成。

## 气候、水体与全局环境配置

自 1.25.1 起支持组合切换整套**已加载环境预设**：

1. `list_editor_environment_presets` 按 `climate`、`water_render`、`terrain_render` 查询原生、模组或本地已加载预设，获取精确名称与当前选择。不是按名字猜测“热带”等组合。
2. `preview_editor_environment` 提供稳定 `request_id` 和 `presets` 对象，选择一至三类；三类都指定即组合整套环境。预览返回前后预设及季节/贴图信息，不修改地图。
3. `apply_editor_configuration` 沿用预览的 ID 和 request_id，提交前复核地图配置与选中源预设的完整基线。缺失、重名、源内容改变或无有效季节/曲线的气候预设会拒绝应用。
4. 使用原生编辑器预设选择器的引用切换方式，保留预设完整的天气曲线、季节和材质贴图，不重建或修改源预设；后续单项参数修改仍先复制预设。回读、取消、五分钟过期及保存规则沿用配置操作。

环境预设切换不会自动重画地形、替换植被、调整资源、海平面或城市建筑主题。三类依次设置，异常时可能部分生效；`outcome_unknown` 先查询实际配置，不自动重试。成功仅证明引用已回读一致，外观、模拟及保存重载仍需实机验收。

外部 PNG/TGA 等文件需要原生贴图导入器转换、资产数据库登记及地图打包，当前接口尚未开放文件导入；可切换已有地表预设内的整套贴图。

先用 `get_editor_configuration` 读取地图实际配置及 `fields` 参数清单，只修改明确开放的字段。`values.seasons` 包含现有季节索引、名称及参数；保留季节身份，不自动替换季节资产。

支持范围：

- 气候：经纬度、太阳高度与钳制起点、冻结温度、随机种子；逐季调整开始时间、昼夜温度及偏差、降水概率/强度/偏差、云量概率/强度/偏差、扰动、极光概率和强度。修改后重建原生气候曲线。
- 水体：海平面、海面风强度和方向。旧版水源须先在原生编辑器转换。修改海平面调整边界/背景水位，不调用全图重置或将所有陆地直接填水，仍须模拟验证流动和淹水范围。
- 风：地图主风向，单位度；按原生气候面板方式设置单位方向向量及压力 40，会重设风场。
- 水面环境：颜色、散射颜色、波浪/湖面波浪、泡沫、焦散、涟漪、光滑度、吸收与折射距离、光散射，以及海风是否影响波浪方向。
- 地表参数：三向混合强度及四组附加材质的泥土覆盖、混合范围、模糊深度和高度偏移。效果取决于已有贴图；整套已加载环境资产使用上述预设流程切换，仍不导入外部贴图或单独替换天气特效。

操作顺序：

1. 暂停并回到默认工具，读取配置后调用 `preview_editor_configuration`，提供稳定 `request_id` 和 1–128 项 `changes`。
2. 每项包含 `path`、`value`；`season.*` 额外提供 `season_index`。范围和数组维度以 `fields` 为准。温度为摄氏度，`m_TempNightDay` 顺序为 `[夜间,白天]`；颜色为 `[R,G,B,A]` 0–1；季节降水/云量概率和强度为 0–100，极光强度和扰动为 0–1。季节开始时间为年内 0–1（不含 1），全年循环间隔至少 0.0001。
3. 预览返回修改前后参数，不修改世界。使用相同 `request_id` 和返回的 `operation_id` 调用 `apply_editor_configuration`。提交前检查整个配置基线；手动修改、切换预设等导致变化时拒绝写入。
4. 写入时先克隆相关预设，在副本完成参数修改及气候曲线重建，再注册并切换地图引用，保留原预设，避免直接修改内置或共享资产。
5. 用 `get_editor_configuration_operation` 查询结果，再用 `get_editor_configuration` 回读。`completed` 表示参数已应用且回读一致，仍须检查效果、运行模拟并保存重载。`outcome_unknown` 可能包含部分更改，先查原操作和实际配置，不能换新请求重做。

未提交预览用 `cancel_editor_configuration_preview` 取消，五分钟过期，换图后 ID 作废，每会话最多 1024 次。不会自动撤销或保存。`get_climate_state` 可读即时天气；`set_weather_override` 没有在编辑器开放，临时天气覆盖不能替代地图气候配置。

示例只生成预览，季节索引必须先查询当前地图：

```json
{
  "request_id": "map-climate-01",
  "changes": [
    { "path": "climate.m_Latitude", "value": 35 },
    { "path": "season.m_TempNightDay", "season_index": 0, "value": [5, 16] },
    { "path": "water_render.m_WaterColor", "value": [0.14, 0.5, 0.6, 1] }
  ]
}
```

## 地形

复用 `sample_terrain` 和 `preview_terrain` → `apply_terrain` → `get_terrain_operation`。支持抬升、降低、整平、平滑、坡面、整图陆地抬升、整图平整和局部浅水清除；具体参数和副作用见[地形指南](TERRAIN-GUIDE.md)。

先暂停模拟并回到默认工具，记录位置、刷宽、基线及影响范围；预览是参数校验与采样，不是可撤销的可视化地形副本。只在明确范围内提交，完成后重新采样。`flatten_map` 具有全图影响，且可清水及删除水源，不能用来替代局部山坡修整。出现未知结果查询原操作，不重复应用刷子。

## 水源

复用 `list_water_sources`、`create_water_source`、`update_water_source`、`delete_water_source`。编辑器中修改要求模拟暂停、默认工具空闲；保留原参数，创建后按返回 ID 回读，删除则等待原生清理后确认目标不存在。

水源工具是直接写入，不具有虚构的 preview 接口或自动重试保证。发生超时先查询是否已创建，不能重复注水。`height_m`、`constant_depth`、`multiplier` 依现有接口的原生语义使用；不要把所有水源类型都当成同一水位。运行模拟检查水面、溢流和稳定状态，回读实体成功不证明湖泊或河流已经稳定。

## 自然资源

首版可直接编辑原生矿石 `ore`、石油 `oil`、肥沃土地 `fertility`、地下水 `groundwater`。鱼群由水域模拟派生，森林资源通过树木构成，不提供虚构的 `fish`、`forest` 或独立 `coal` 图层。

1. 用 `read_environment_grid` 读取当前自然资源或地下水网格和原始值。资源是地图格数据，不是企业库存，不能使用 `set_resource_amount` 替代。
2. 调用 `preview_map_resources`，提供稳定 `request_id`、`resource`、`center:{x,z}`、半径 56–2000 米及整数 `value` 0–10000。值为原生单位，不是百分比。
3. 圆形范围必须完整在地图内；仅选择四角都在圆内的网格单元。预览返回中心、半径、单元大小、数量、面积和原值范围，实际受影响面积可能小于圆面积，过小或偏置的刷子可能没有完整格子。
4. 使用 `apply_map_resources`，沿用预览的 `request_id` 和返回的 `operation_id`。提交前逐格检查目标资源基线及网格尺寸；手动编辑导致变化时拒绝全部写入。
5. 使用 `get_map_resource_operation` 回读终态；`completed` 表示所选原生网格已写入并读回一致，不表示已保存地图。取消未提交方案使用 `cancel_map_resource_preview`。

自然资源仅修改选中图层，设置基础量并重置该图层的消耗量；不改其他资源。地下水同时设置当前量与容量，原污染量仅在超过新容量时截断。值为 0 表示清除所选资源。预览五分钟过期，每会话最多 4096 次，不支持自动撤销；失败或结果未知必须查原操作，换图后所有操作 ID 作废。

示例：在已确认区域预览原生矿石浓度，不会立即写入：

```json
{
  "request_id": "map-ore-region-01",
  "resource": "ore",
  "center": { "x": 0, "z": 0 },
  "radius_m": 200,
  "value": 5000
}
```

坐标仅为参数示例，实际制作先读取当前地图。资源修改采用与原生编辑器资源导入相同的 CellMap 数据层，完成相关依赖后写入并标记地图资源区域更新；不是修改企业经济数据。

## 植被

用 `list_landscape_prefabs` 选择当前地图实际存在的树木/植物，`list_landscape_objects` 查询现状。支持放置、图案种植、移动、树龄/状态调整、指定对象移除及限定区域清理。参数沿用现有接口，单次放置最多 256 个；大范围种植分批回读，不用相同批次重复覆盖。

先暂停并退出其他编辑工具；创建前校验整批位置与地形。编辑器不套用城市进度锁定，但仍需真实已加载的 prefab。需要地图自然植被时显式传 `natural=true`，不能把普通装饰树自动宣称为森林资源。种植后读取永久对象、位置及状态，运行编辑器模拟后再核验森林资源和生长。直接写操作超时先查实体，不盲目重放。

## 保存、验收与部署

所有配置、资源及地形预览完成或取消后，`show_editor_save_panel` 打开原生地图保存面板。该操作返回 `saved=false`，由玩家选择文件名并确认，绝不表示地图已保存，也不自动覆盖或上传。保存之后是否可玩，还须通过原生编辑器要求及重新加载验证。

部署新的模组 DLL 前保存并关闭游戏，使用官方构建流程；开发期间 `build.ps1 -Stage` 只写暂存目录。重新启动编辑器后先检查 bridge 版本、Editor 状态和工具清单，再对用户明确指定的小范围进行地形、水源、资源和植被实测。自动测试及构建通过不代替编辑器实机验收。

本功能当前的验证记录应分别列出：自动测试、官方构建、编辑器只读查询、各类写入与永久回读、保存及重载。没有实时证据的项目保留“待实测”，不能据此说明已修改用户当前地图。

## 编辑器船舶航道（1.25.2）

已开放航道查询、预览、提交、取消和拆除，具体见[航道指南](../transport/WATERWAY-GUIDE.md)。需要真实水面和足够全宽水深，不自动挖河注水；环路施工须验证永久端点闭合，不代表创建了客货航线或对外连接。

## 普通道路建设（1.25.3）

支持 `list_road_prefabs` → `preview_road` / `preview_road_route` / `preview_road_ring` → `get_road_operation` → `build_road`，未提交时使用 `cancel_road_preview`。直线、二次及三次曲线沿用每段 16–256 米限制；连续直线路线最多 16 点，小型圆环半径 12–160 米。大型沿岸环路须分段建设，不能把小型圆环工具用于整张地图。

编辑器不使用城市资金和进度解锁检查；目录仍返回原始 `locked` 状态，不修改解锁组件。原生临时网络、坡度、碰撞、错误/警告、费用上限、暂停、默认工具空闲、幂等请求与过期检查继续生效。普通道路升级、拆除、网格、直接改高程、车道政策及其他网络仍未开放。

首批开工前发现精确道路 prefab、车道数和单向属性，并采样岸线内侧地形及水深。分批用永久 `node_id` 续接；末批明确复用首节点闭环。用 `query_entities` / `get_entity_components` 回读永久道路、曲线和端点，必要时用 `inspect_road_lanes` 检查车道，`find_roads_by_name` 可查有名称的道路。仅 `completed` 和永久拓扑回读证明施工完成，不能把城市模式测试或编译通过当作编辑器内实际通车验证。

默认行车方向使用地图配置；配置系统不可用时小圆环按右行交通取逆时针，也可明确传入方向。保存窗口在道路或航道事务未结束时拒绝打开。需玩家保存地图；部署更新前先保存并退出游戏。

## 通用资产目录与原生放置（1.26.0）

“所有资产”指**当前游戏已加载的全部 prefab 类型可发现和检查**，不代表每个内部数据资源都是可放置实体，也不代表所有内容已逐个通过实机验证。目录动态包含内置、DLC、本地和已加载模组资产；缺少的内容不自动下载、解锁或导入。`source.content_available=false` 时拒绝放置。

### 发现与选择

- `list_editor_assets`：按名称/类型搜索，可筛选 `object`、`stamp`、`network`、`area`、`data`、`outside_connection`，稳定排序并按 `next_offset` 翻页。返回精确 `prefab_id`、名称、类型、原始锁定状态、内容来源及自动放置能力。资产热加载后重新查询；跨会话 ID 不可复用。
- `get_editor_asset`：读取一个资产的分类、原生放置条件和来源。重名必须使用 `prefab_id`；名称和 ID 同时传入时必须匹配。
- `select_editor_asset`：请求原生 `ToolSystem.ActivatePrefabTool` 选择该资产，覆盖原生接受的特殊工具。仅选中工具，**不会永久放置**；返回 `selected=false` 表示没有原生放置工具接受它。气候、材质、资源、车辆模板、内部组成数据等使用对应配置/专用编辑器，不能伪装成地图建筑。此入口不执行任意 prefab 字段写入。

### 自动放置的四类入口

统一调用 `preview_editor_asset`，再轮询 `get_editor_asset_operation`，通过后 `apply_editor_asset`，最后回读永久实体；取消用 `cancel_editor_asset_preview`。需要暂停、默认工具且无其他临时预览。每会话最多 4096 个事务，预览有效期五分钟；同一请求重试必须沿用 ID 和完全相同参数，未知结果先查询原事务，禁止换 ID 重建。

| 类别 | 输入与适用范围 |
| --- | --- |
| `object` | `position:{x,z,y?}`、可选旋转和 `parent_id`；原生建筑、道具、树木、标记及对外连接对象。RoadSide 资产必须提供真实永久道路父边，并验证实际绑定；OwnerSide 资产必须提供父对象。特殊升级的兼容关系仍由原生预览判定。 |
| `stamp` | TransformPrefab / AssetStampData 组合资产的位置与旋转；通过原生组合放置流程生成对象及附属网络，核验全部新几何结果。 |
| `network` | 2–16 个 `points`，可附 `node_id` 连接已有网络，及每段一个二次/三次曲线定义；每段 16–256 米。支持具备原生几何和可放置数据的道路、轨道、管线、路径、航道等预制件，原生连接层、坡度和碰撞仍生效。通用入口不提供中途拆边和网络升级。 |
| `area` | 3–128 点的简单多边形，不重复首点；支持表面和原生区域资产，可提供所属 `parent_id`。自交、退化、多余网络参数均拒绝。 |

对象与网络点的显式 `y` 均为绝对高度；省略时采样地面。浮动/悬浮对象和浮动网络省略 `y`，自动使用原生水面及对象的原生偏移；浮动对象同时核验地形相对高差，避免抬起海底。航道额外使用现有全宽采样验证，最低水深 4 米；更专门的曲率/宽度规划仍优先使用水路工具。一般网络仍保留各 prefab 的原生高程范围。

每次提交重新检查父对象、端点、费用、预览几何、错误与警告；任何现有对象删除都阻止提交。原生预览和 `GetAllowApply` 不能跳过。`completed` 要求所有新对象/曲线/多边形变成永久实体，prefab、坐标、旋转、边界及网络节点邻接与预览相符。建筑道路绑定、浮动高度和对外连接组件另行核验。不把完整地图制作、建筑投产、外部车辆产生或地图保存算作此事务的成功条件。

### 飞机对外连接

1. 在 `list_editor_assets(kind="outside_connection")` 中发现当前真实资产，以 `transport_type` 和原生数据确认飞机类型，不能猜名称。
2. 使用该接口返回的 `world_bounds`，它取自原生 `TerrainUtils.GetBounds`，与购买地块/可建造区域边界不同。
3. 选地图两个对角边界位置，检查地形、已有连接及预设条件。按原生外向旋转放置；悬浮飞机连接点省略 `y`，自动计算水面/地面加预制件悬浮偏移（当前飞机资产偏移为 1000 米）；省略旋转时自动朝向世界边界外侧，实时预览仍须验证，不沿用石油平台或道路高度规则。
4. 每点分别预览、提交、回读 `Game.Objects.OutsideConnection`、位置与 prefab；如为交通站点，额外回读其交通类型。几何放置成功不等于航线已运营。

### 部署与验收
