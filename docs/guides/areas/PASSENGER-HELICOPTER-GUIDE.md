# 直升机 MCP 可选适配

直升机模型、运输模拟、界面、资源和发布工具由同级独立项目[Transport Fever 3 Helicopters](../../../../TransportFever3Helicopters/README.md)维护。

自MCP桥接1.37.4起，不再引用其程序集或要求其源码目录存在。普通MCP功能可独立构建运行。直升机查询、建线及诊断通过可选适配访问已启用的独立模组；缺失或不兼容时专用写入拒绝执行，不主动加载DLL、启动模拟或跳过校验。完整历史见[独立项目记录](../../../../TransportFever3Helicopters/docs/guides/areas/PASSENGER-HELICOPTER-GUIDE.md)。

旧存档组件迁移条件和当前本地版本见[项目信息](../../reference/PROJECT-INFO.md)。
