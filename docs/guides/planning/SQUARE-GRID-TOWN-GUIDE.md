# 方形网格城镇与受控外围连接

用于正方形城镇、均匀内部网格、单向外围道路及高速接驳的联合规划。方形、外围七车道、每面保留三个连接口来自本次用户方案，不是其他城镇的默认车道或出口数量。

## 规划参数与缩小方案

记录实际世界边界、中心、朝向、边长、道路全宽、内部等间距及所需外部连接。当前镜头只是选址范围，还须检查已购土地、水域、地形和既有设施。

面积调整与边长调整不同：若保留原面积的比例为 r，保持正方形时边长乘以 sqrt(r)。例如“减少四分之一”对应面积 75%、边长约 86.6%；“缩为四分之一”对应面积 25%、边长 50%。表述不清时先查已接受的方案参数，无法确定再澄清，不能从一句“约四分之一”擅自选定含义。

缩小后重新计算道路中心线、整齐格距、格数、对外接口和建筑预留，不能只缩放图片或保留原地形/绑定结果。必要时按原生格网约束调整格数或边长并报告差异，不能让末排留下不等宽碎格。

## 均匀网格与外围接口

内部横纵道路按等间距排列，优先同一兼容 prefab 和统一宽度。外围道路宽度独立计算，外围与内部净距要避免道路包络重叠。规则部分优先保存在 `plan.grids[]`，使用网格工具；不能无损表达的断开边界或接驳部分记录 `grid_exceptions` 并单独表达，不强行让网格工具自动补齐全部接口。

每面只保留指定数量的接口时，先列出四面的接口坐标和所连内部道路，沿各边均匀布置，保护转角及路口退距。未保留的网格道路应在外围前结束并留出真实净空，不能只在图片中隐藏连接线。检查工具的自动吸附和 auto-connect 不会重新接上被删去的接口。

外围按要求选择真实单向资产，回读城市行车侧、边方向和车道。角部及复杂接驳使用平滑曲线，不能把视觉闭合当成有向可达。左侧、上方高速分别发现真实来去方向与永久节点，设计兼容接驳，不能用普通道路视觉接触替代合法高速出入口。

## 施工与断点续建

规划变化后重新渲染并按当前工作流更新计划版本；旧批准图不能代表新边界或新接入口布局。沿原施工记录分批预览、提交、永久回读，已完成边保持记录，剩余批次不得把已建道路重复创建。

道路原生分割或合并后使用返回的新永久 ID，重新核对节点及接口数。遇到 `TOOL_BUSY`、`USER_CHANGED_TOOL`、失败或结果未知，按[事务恢复](../../workflows/operations.md)处理；恢复时先确认会话和永久对象，再继续原断点。

## 验收

- 根据永久道路中心线与宽度检查正方形边界、内部等间距和实际面积，而非 SVG 像素。
- 分别统计每面的实际内外连接，检查未保留道路是否被自动接入；本次每面三个不能写成通用最大值。
- 验证外围单向闭环、全部内部道路到出口及城市外部网络的有向可达性。
- 土地划区另走 zoning 验收；道路完成不代表住房、服务建筑或人口已经生成。
- 保存最终方案版本、永久对象、费用及未完成项。卡片初始视野显示本次城镇与必要高速端点，不默认全地图；已有卡片不重复打开网页，施工聚焦保持当前缩放。
